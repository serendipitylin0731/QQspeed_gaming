# 极速仓库

基于 `DESIGN.md` 实现的 QQ 飞车本地资料与赛事管理应用。

## 已实现

- 地图仓库：星级与图池筛选、部分名称搜索、图池批量管理、最多 15 张王图、个人纪录与录像口令
- 赛车图鉴：等级筛选、部分名称搜索、皮肤添加与展示皮肤切换
- 官方同步：启动时从 QQ 飞车手游官网增量合并地图和赛车列表
- 随机转盘：基础/星级/排除条件、自定义图池、不重复抽取、状态重置、最多 100 个配置
- 赛事计分台：玩法选择、2–6 方计分、大分、本局分数、横向历史赛道与逐局得分记录
- 玩法规则：直接打包并展示 `gamemode` 中的 Markdown 文件
- 本地持久化：数据自动保存，可导出和恢复 JSON 备份

## 运行

```powershell
npm install
npm run dev
```

## 构建 Windows 安装包

```powershell
npm run dist
```

安装包输出到 `release/极速仓库 Setup 1.0.0.exe`。

> 应用数据只保存在本机 Electron 用户数据目录。官网资料和封面需要联网同步与显示。
