# kvk接力抢n

## 基础设置

需定义变量：k, n

两队各k人，分别定下出场顺序，双方第一位出场的完成抢 (n//k + 1)，一方到达该分数之后，第二棒接力这个分数继续打
- k=2时，直到有一方得到n分获胜
- k=3时，第二棒有一方打到 (n - n//k) 分时换第三棒，打到n分获胜

| 项目 | 实行方式 |
|:---:|:---:|
| 得分方式 | 获胜得一分 |
| 获胜方法 | 得到 n 分晋级 |
| 选图权归属 | 总分落后方 / 随机图 |
