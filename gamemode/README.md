## 玩法格式介绍

> 所有玩法都需要提前规定好选图图池，再开始游戏

### 常规玩法文档

#### 1. 文件头

文件头需要用 `tag` 规定游戏模式、游戏人数:
- 游戏模式：`individual` —— 个人竞速；`team` —— 组队竞速。
- 游戏人数：`plyr_1`、`plyr_2`、`plyr_3`

#### 2. 正文

应当按照以下示例格式表述内容

```markdown
# 标题
## 基础设置

需定义变量：

| 项目 | 实行方式 |
|:---:|:---:|
| 得分方式 |  |
| 获胜方法 |  |
| 选图权归属 |  |

## 可选玩法
```

#### 示例：
```markdown
---
tags: individual, plyr_1
---

# 1v1单挑抢n

## 基础设置

需定义变量：n

| 项目 | 实行方式 |
|:---:|:---:|
| 得分方式 | 获胜者得1分 |
| 获胜方法 | 先得到 n 分者获胜 |
| 选图权归属 | 落后方 |

## 可选玩法

- 首图：随机图 / [计时挑战赛](./internal/计时挑战赛.md)
- 获胜条件： [鏖战](./internal/鏖战.md) / [巅峰鏖战](./internal/巅峰鏖战.md)
```

### 特殊玩法文档

直接解释特殊玩法的触发条件和具体玩法，示例如下
```markdown
# 全速对决

## 触发条件

在积分赛中，对局结束双方分差在h分以内触发

## 玩法规则

在全部比赛开始之前预选全速对决赛道，双方各一张，必须为5星及以上赛道

若触发，所有赛车使用刷新，加赛这两张赛道，先打落后方的赛道，再打领先方的赛道

结束后总分高的获胜，若相等最后一局第一冲线方获胜
```

> 术语解释
>
> 落后方：总分落后方；同分时最近一次被追平的一方

## 游玩方式

实际游玩时，可以选择一些模式组合变成几大局，一轮获胜获得一大分；也可以用[计时挑战赛](./计时挑战赛.md)作为第一轮首图的选择权归属，不计大分

故设计时在某一局结束之后要允许继续下一轮，并且统计大分

每大局的首图可以是随机图，可以是指定地图，也可以是大分落后放选择
